# email-mcp

Pointers to the **official** Notify MCP for coding agents.

## Primary repository

**[notifycx-mcp](https://github.com/email-mcp/notifycx-mcp)** — install docs only.

```bash
npx -y notifycx-mcp
```

Set `NOTIFY_API_KEY` from https://notify.cx/dashboard/credentials

**Source of the package:** https://github.com/notifycx/notifycx (directory `mcp/`)  
**Product page:** https://notify.cx/mcp

This org does **not** publish a second MCP server. Prefer the official `notifycx-mcp` npm package; ignore archived legacy SSE projects.
